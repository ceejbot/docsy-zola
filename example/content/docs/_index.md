docsy-zola reproduces the docsy documentation layout under Zola 0.23 or newer:
Bootstrap 5, a foldable left-nav tree, a right-hand table of contents,
breadcrumbs, page-source and edit links, light/dark/auto colour modes, and
offline search over Zola's own index. The templates are Tera 2 components.
